# Clinic Agent 2.0 — Python + FastAPI

نسخه مستقل و اولیه سامانه کلینیک؛ پروژه دانشگاهی قبلی را تغییر نمی‌دهد.

## اجرای محلی
Python 3.10+ لازم است:
```bash
python -m venv .venv
# ویندوز: .venv\Scripts\activate
# مک/لینوکس: source .venv/bin/activate
pip install -r requirements.txt
# .env.example را کپی و نامش را .env بگذارید
uvicorn app.main:app --reload
```
سپس `http://127.0.0.1:8000` را باز کنید.

## حساب‌های آزمایشی
- مدیر: admin@clinic.local / Admin123!
- پزشک: doctor@clinic.local / Doctor123!
- بیمار: patient@clinic.local / Patient123!

## فعال‌سازی AI
در تنظیمات محیطی سرور، `OPENAI_API_KEY` را وارد کنید. کلید را داخل فایل‌های فرانت‌اند یا GitHub قرار ندهید. نام مدل از `OPENAI_MODEL` خوانده می‌شود (پیش‌فرض `gpt-4.1-mini`). بدون کلید، چت پاسخ AI تولید نمی‌کند.

## انتشار در Render
محتویات پوشه را در یک مخزن GitHub جدید و مجزا بارگذاری کنید، سپس در Render از New → Blueprint مخزن را متصل کنید. در صورت درخواست کارت/پلن پولی، پیش از تأیید هزینه توقف کنید. Blueprint یک دیسک پایدار ۱ گیگابایتی تعریف می‌کند که ممکن است پولی باشد؛ رایگان‌بودن وب‌سرویس لزوماً دیسک پایدار را پوشش نمی‌دهد.
